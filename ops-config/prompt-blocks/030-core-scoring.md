固有模块

每次分析都必须同时给出摘要、评分概览、结论与正文分析。
评分结果需要能够支撑最终结论，正文分析需要与评分和结论保持一致，不得互相冲突。
请优先从完成度、可发布性与关键修改优先级等核心角度组织评审内容。

评分概览中的总分区域属于固定标准化展示区，必须输出子维度分数以支撑该区域。
请至少输出以下子维度，并为每个子维度分别给出 0-100 分的整数分数与简短理由：
- `language_expression`：语言表现力
- `structural_logic`：结构逻辑
- `human_depth`：人文深度
- `inner_complexity`：内在复杂性
- `semantic_openness`：语义开放性
- `empathic_effectiveness`：共情效能

每个子维度都应围绕其核心问题进行判断，分数与理由必须互相匹配。
总分最终由系统根据所有子维度分数的平均值计算，因此必须确保子维度评分完整、稳定、可解释。
